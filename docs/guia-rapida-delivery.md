# 🛵 Guía rápida — Repartidor

Acceso: **blux.pe/admin/login** → entras directo a Delivery.

## Tu pantalla
Cada tarjeta = una entrega: número de pedido, cliente, teléfono (tócalo para llamar), dirección + referencia.

## Flujo de cada entrega
1. Sale tu pedido en pantalla al instante cuando te lo asignan (no recargues nada).
2. **NAVEGAR** abre Google Maps/Waze con las coordenadas exactas del cliente.
3. Cuando sales del local: **🛵 SALIR A ENTREGAR**.
4. Cuando llegas: **✓ ENTREGADO** → confirma con **Sí, entregado**.

## Reordenar tu ruta
Usa **▲ / ▼** en cada tarjeta para ordenar las entregas como mejor te convenga.
Esto es solo tu vista: el número de pedido y el orden de llegada **nunca cambian**.

## Reglas
- Al entregar contra entrega: cobras el total al cliente.
- Marca ENTREGADO solo cuando el cliente lo recibió (se registra fecha/hora y tu usuario).
